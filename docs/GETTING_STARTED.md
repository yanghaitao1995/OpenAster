# 第一次使用

本地安装步骤见 [README](../README.md#在电脑上运行网页版)。启动后打开 `http://127.0.0.1:4317`，按下面的顺序试一次完整任务。

## 选一个项目

点击 **工作空间 → 新建项目**，选择父目录、填写项目名，再点击 **新建并打开**。已经有项目时，使用 **打开项目**。界面会显示实际路径，最近打开过的项目可以直接切换。

网页和桌面使用同一套项目入口。手机连接的是服务主机：手机里看到的路径也是主机路径，文件不会因此搬到手机上。运行中的任务、待处理审批和未完成的文件操作会阻止切换，先处理它们再换项目。

## 发送第一条消息

不配置模型也能先试演示模式。它使用固定的本地响应，便于熟悉界面，不产生模型费用。

连接自己的模型时，在设置里选择协议，填写服务商提供的地址、模型名和 API Key。先发送：

```text
只回复 OK。
```

这一步只检查基础连接。图片、流式响应和工具调用还取决于服务端是否支持。图片可通过输入框的附件按钮选择，也可以直接粘贴；发送前能预览和移除。

网页模式的 API Key 只在当前服务进程中使用，重启后需要重新填写；桌面模式可使用系统凭据保护。不要把 Key 写进任务消息。

## 看懂一次执行

任务对话中会陆续出现模型输出和工具执行过程。代码块支持复制与切换换行；宽表格在自身区域内横向滚动。

待审批操作会显示需要你决定的内容。处理后的审批移入任务详情，最终答复末尾不再重复堆放审批历史。文件修改先看差异，命令执行先看命令、参数和工作目录。

任务执行时仍然可以输入：普通发送用于补充要求，消息保存后在安全节点处理；**打断并发送**请求停止当前步骤，再处理新要求。取消或打断不会撤销已经完成的文件修改或外部请求。任务正等待审批时，新要求会使旧审批失效，避免继续执行过时的决定。

## 选择命令权限

任务详情中可以调整当前任务的命令策略：

| 策略 | 使用方式 |
| --- | --- |
| 智能审批 | 默认选项；少量明确的只读命令直接执行，其他命令逐次确认 |
| 每次询问 | 每个 Shell 命令都需要确认 |
| 本轮授权 | 明确确认风险后，允许符合规则的常见开发命令；高风险或无法判定的命令仍需单独处理 |

授权只属于当前任务运行，结束后恢复默认，也可提前撤销。它不会把文件修改一并授权。Shell 使用主机当前用户的权限，任务授权不构成操作系统沙箱。

## 搜索与阅读网页

在设置中打开**联网搜索与阅读**，再选择支持工具调用的模型。可以发送“搜索 Node.js 官方文档，概括它的用途，并附上来源”，也可以直接给出一个公开的 HTTPS 网页地址，请模型提取要点或比较内容。

搜索词会发送给 DuckDuckGo；读取的网页文字会交给当前模型理解。页面中的标题、链接和正文可以在工具执行记录中查看，答复中的来源应与这些记录对应。不要在搜索词或网址中放入密钥、访问令牌或私人资料。

开关默认关闭，只在当前服务会话内有效。关闭会取消尚未结束的网页请求；服务重启或切换项目后需要重新开启。它不影响已经获准的 Shell 命令自身是否能访问网络。

目前读取公开的 HTML、纯文本和 Markdown 页面，不执行网页脚本，也不读取登录后的内容。搜索遇到限流或验证页时会报告失败；可以稍后再试，或给出已知的公开页面地址。扫描版 PDF、视频和主要依靠 JavaScript 加载正文的网站不在本次支持范围内。

## 从手机连接主机

手机端需要先有一个指向本机服务、证书被手机信任的 HTTPS 网关。普通的 `http://127.0.0.1:4317` 仅代表当前设备自身，不能作为另一台手机的服务地址。

主机启动前配置下面的环境变量：

| 变量 | 含义 |
| --- | --- |
| `OPENASTER_GATEWAY_ORIGIN` | 完整 HTTPS 来源，如 `https://agent.example.com`，不带路径 |
| `OPENASTER_GATEWAY_TOKEN` | 至少 32 字符的独立随机访问令牌，不是模型 API Key |
| `OPENASTER_ALLOWED_ORIGINS` | 允许的手机界面来源；Android 为 `https://localhost`，iOS 为 `capacitor://localhost`，多项用逗号分隔 |

例如，在 PowerShell 中设好实际网关域名后生成一个本次启动使用的令牌：

```powershell
$env:OPENASTER_GATEWAY_ORIGIN = 'https://agent.example.com'
$env:OPENASTER_GATEWAY_TOKEN = node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
$env:OPENASTER_ALLOWED_ORIGINS = 'https://localhost,capacitor://localhost'
pnpm start
```

把示例域名换成自己控制的域名。HTTPS 反向代理需要将该来源转发到本机 `127.0.0.1:4317`，保留公开 Host，并支持 SSE 持续连接；服务本身仍在回环地址监听。域名、证书和反向代理需由部署者准备，上述变量不会自动申请证书。

在手机的网关设置中填写这个 HTTPS 地址和独立访问令牌。令牌只在自己控制的设备间传递，不写进仓库或截图。没有可信 HTTPS 环境时，可以先使用本地网页版和桌面版。

## 遇到问题

- **端口已占用**：按 README 修改 `PORT`，或关闭此前启动的 OpenAster 服务。
- **服务商拒绝请求**：核对协议、地址、模型权限与额度，保留错误码即可，无需公开完整连接信息。
- **输出中断**：已经收到的片段会保留，未完成状态不会当作最终答案；检查执行记录再决定是否重试。
- **目录无法打开**：确认目录位于允许的范围，没有经过链接或跳转到受保护位置。
