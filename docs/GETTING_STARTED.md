# 快速开始

先使用不含敏感信息的测试目录体验。OpenAster 仍是实验性个人项目；使用真实模型、文件或命令前，请了解[安全模型](SECURITY_MODEL.md)。

## 准备环境

- Node.js 24。
- `package.json` 的 `packageManager` 字段指定版本的 pnpm。
- 一份来源可信的项目源码，以及你有权使用的本地测试目录。

在项目根目录执行：

```sh
pnpm install --frozen-lockfile
pnpm start
```

安装依赖会访问软件源。服务启动后，打开终端显示的本地地址。停止时在对应终端按 `Ctrl+C`。如果启动失败，保留经过脱敏的错误码，不要公开整个环境变量或配置文件。

## 先体验演示任务

选择内置演示模式，发送一个简单任务并观察任务状态、工具请求和批准流程。演示模式使用本地确定性行为，不调用真实模型；它用于理解交互，不能用来衡量模型能力。

在项目或工作区界面核对实际路径，再创建或选择测试项目。不要把系统目录、个人资料全集或公司资料目录作为首次体验的工作区。不同启动方式可能使用不同的数据目录，实际位置以当前界面和启动配置为准。

## 连接自己的模型

在模型设置中选择合适的协议适配器，填写服务方提供的地址、模型标识和所需凭据。仅填写你有权使用的连接信息；不要把密钥写入源码、截图或 Issue。

首次测试可使用“只回复 OK”一类短指令，确认协议、权限和计费是否符合预期。短文本请求成功不代表图片、工具调用或流式协议均已兼容；逐项启用所需能力。

任务上下文可能包含消息、选定图片、技能内容和工具读取的文件。连接外部服务前确认这些内容允许发送，并了解提供方的使用条款和数据政策。

## 公开思考与中断输出

提供方支持时，可以查看其显式返回的公开思考内容或摘要。应用不会推断未返回的内部思维，也不将签名、隐藏或加密字段作为可读思考展示。不同协议和模型的支持范围可能不同。

默认 120 秒限制用于连接等待与传输空闲：收到传输活动会重新计时，并不是所有生成请求必须在 120 秒内结束。任务仍受总时长和输出保存上限约束，不代表可以无限运行。

如果输出中途断开，已经接收的内容会保留并标记为未完成；连接重试的不同尝试分开记录，不把中断片段当成最终答复。达到保存上限时会明确报错，应缩小请求或新建任务继续。再次操作前，先检查已有输出和工具执行记录。

## 批准一次操作

遇到文件修改或命令请求时，阅读实际目标路径、参数、预期变更和可能的外部访问。无法判断时拒绝该请求或缩小任务。批准并不保证操作安全，也不表示后续请求自动获准。

对于会产生副作用的任务，先使用可丢弃的样例。取消任务可以停止后续工作，但不能保证撤销已经完成的文件修改或外部操作。
