# 第一次使用

本地安装步骤见 [README](../README.md#在电脑上运行网页版)。启动后打开 `http://127.0.0.1:4317`，按下面的顺序试一次完整任务。

## 开始前先确认

当前是 Vibe Coding 学习项目的预览版，依据 [Apache License 2.0 原文](../LICENSE)以“现状”提供，不保证无错误、绝对安全或适合特定用途；法律不允许排除或限制的责任不因此排除或限制。本说明不改变许可证。

先核对 [Release](https://github.com/yanghaitao1995/OpenAster/releases) 中该包的版本、系统与架构、签名状态和 SHA-256；未列出的包尚未提供。Windows 预览包未作发布者代码签名，macOS 预览构建未公证，Android 调试包不是商店正式版；当前没有可直接装到 iPhone 的 IPA。完整条件见[平台说明](PLATFORMS.md#各平台安装与使用条件)，不要绕过系统防护或证书警告。

首次操作使用练习目录，重要文件先备份。核验 AI 生成的代码、答案和来源，确认第三方模型与搜索费用。对话、已发送图片、参与任务的文件内容和工具结果可能交给所选模型；搜索词交给搜索服务。只提交有权使用的资料，密钥不要写入对话。授权命令使用主机当前账户权限，审批不是操作系统沙箱。

本机 HTTP 服务只用于回环访问。远程浏览器和手机均需可信 HTTPS 网关及认证；iPhone 可通过 Safari 使用这样部署的网页版，不能通过忽略 TLS 错误连接。

## 选一个项目

点击 **工作空间 → 新建项目**，选择父目录、填写项目名，再点击 **新建并打开**。已经有项目时，使用 **打开项目**。界面会显示实际路径，最近打开过的项目可以直接切换。

网页和桌面使用同一套项目入口。手机连接的是服务主机：手机里看到的路径也是主机路径，文件不会因此搬到手机上。运行中的任务、待处理审批和未完成的文件操作会阻止切换，先处理它们再换项目。

## 发送第一条消息

不配置模型也能先试演示模式。它使用固定的本地响应，便于熟悉界面，不产生模型费用。

连接自己的模型时，在设置里选择协议，填写服务商提供的地址、模型名和 API Key。先发送：

```text
只回复 OK。
```

这一步只检查基础连接。图片、流式响应和工具调用还取决于服务端是否支持。图片可通过输入框的附件按钮选择，也可以直接粘贴；发送前能预览和移除。

网页模式的 API Key 只在当前服务进程中使用，重启后需要重新填写；桌面模式可使用系统凭据保护。不要把 Key 写进任务消息。

## 看懂一次执行

任务对话中会陆续出现模型输出和工具执行过程。代码块支持复制与切换换行；宽表格在自身区域内横向滚动。

待审批操作会显示需要你决定的内容。处理后的审批移入任务详情，最终答复末尾不再重复堆放审批历史。文件修改先看差异，命令执行先看命令、参数和工作目录。

任务执行时仍然可以输入：普通发送用于补充要求，消息保存后在安全节点处理；**打断并发送**请求停止当前步骤，再处理新要求。取消或打断不会撤销已经完成的文件修改或外部请求。任务正等待审批时，新要求会使旧审批失效，避免继续执行过时的决定。

## 长任务与上下文

模型设置里的**输出与上下文**决定一次请求能写多长、能带多少资料；**长任务预算**决定任务能继续请求多少次。两者分别设置。

| 设置 | 新连接默认值 | 可设置范围 |
| --- | --- | --- |
| 每次输出 token | 16,384 | 128–131,072 |
| 上下文窗口 token | 131,072 | 8,192–2,000,000 |
| 每轮主对话模型请求 | 64 次 | 1–512 次 |
| 每轮工具操作 | 256 次 | 1–2,048 次 |
| 执行时间预算 | 60 分钟 | 1–240 分钟 |

窗口和输出值必须与模型实际规格相符；应用默认值不是服务商能力声明。已有连接保存过的值不会被自动覆盖。**应用长任务预设**按钮只调整调用、工具与执行时间，并开启压缩和续写，不替你猜测模型规格。

主对话请求次数包括连接重试、自动摘要和续写。百炼原生搜索另作为工具计数，仍可能产生模型及搜索费用。执行时间计算工具工作与审批等待，模型连接、输出等待另有可取消的超时；单次审批仍在 5 分钟后过期。修改连接设置从下一轮任务生效。

上下文占用是估算值，界面会显示估算输入、配置窗口和预留输出。两者合计接近窗口的 85% 时，程序先将较大的工具结果改为摘录或可回读的引用；仍不足时，显示**正在压缩上下文**，用模型生成早期记录摘要。最新用户指令和最近完整的工具调用保留，原始对话、执行记录和工具结果不删除。摘要通过检查后才显示**上下文已压缩**；失败会保留原记录并停止，摘要不会获得新的操作权限。

自动摘要可能遗漏信息，也会产生模型费用。重要结论应核对原文，文件修改前仍需重新读取、核对和审批。摘要在本轮内复用；下一轮会重新评估历史，必要时再次整理。

服务商明确告知纯文本输出额度耗尽时，会出现**继续生成**步骤，最终按顺序合并正文。缺少完整协议结束标记、包含工具调用或半截工具参数时，不自动续写；网络中断的片段也不会直接拼成答案。每段公开输出及合并后的答复另有 1 MiB 字节上限。

预算耗尽时可以点击**继续任务**，检查输入框中的指令后发送。下一轮会收到上一轮的有限执行记录，重新取得任务预算，但不会继承命令授权，也不会自动重放已执行操作。原始消息总量、工具归档和会话存储仍有容量限制；接近保存容量时会明确停止，较大的任务可通过“摘要续接”转入新会话。

## 选择命令权限

任务详情中可以调整当前任务的命令策略：

| 策略 | 使用方式 |
| --- | --- |
| 智能审批 | 默认选项；少量明确的只读命令直接执行，其他命令逐次确认 |
| 每次询问 | 每个 Shell 命令都需要确认 |
| 本轮授权 | 明确确认风险后，允许符合规则的常见开发命令；高风险或无法判定的命令仍需单独处理 |

授权只属于当前任务运行，结束后恢复默认，也可提前撤销。它不会把文件修改一并授权。Shell 使用主机当前用户的权限，任务授权不构成操作系统沙箱。

## 搜索与阅读网页

在设置中打开**联网搜索与阅读**，再选择支持工具调用的模型。可以发送“搜索 Node.js 官方文档，概括它的用途，并附上来源”，也可以直接给出一个公开的 HTTPS 网页地址，请模型提取要点或比较内容。

默认搜索服务为 Parallel，需要时可在同一区域选择服务，再点击**保存搜索服务**：

| 服务 | 使用方式与限制 |
| --- | --- |
| Parallel | 默认使用[官方 MCP 入口](https://docs.parallel.ai/integrations/mcp/quickstart)免密钥调用；有调用频率限制，第三方服务不保证随时可用 |
| 百炼原生 | 使用当前 Qwen 连接的地址和密钥，要求该地址支持 Responses 搜索；会额外产生模型与搜索费用。自定义兼容地址的支持情况尚未实测 |
| DuckDuckGo | 实验性公开网页入口，可能遇到验证码或页面格式变化，不是稳定的搜索 API |

保存选择不会打开联网开关，也不会立即发送搜索请求。选择仅保留在当前后端进程内，重启后恢复 Parallel；任务运行中或等待审批时不能更改。服务失败后不会自动切换到其他服务，也不会替换已配置的百炼地址。

搜索词会发送给你选择的搜索服务；取得的来源、摘录和网页文字会交给当前模型理解。百炼结果中的模型归纳不等同于网页原文。工具执行记录会保留实际取得的来源，答复中的引用应与记录对应。不要在搜索词或网址中放入密钥、访问令牌或私人资料。

联网开关默认关闭，只在当前服务会话内有效。关闭会取消尚未结束的网页请求；服务重启或切换项目后需要重新开启。它不影响已经获准的 Shell 命令自身是否能访问网络。

遇到验证码、限流、鉴权或服务不可用等错误时，本轮会停止重复搜索，换一个搜索词也不会重新发送请求。仍可给出已知的公开 HTTPS 地址让 `read_webpage` 阅读；它继续遵守原有地址检查、访问权限和内容限制。需要再次搜索时，先检查错误原因，再发送新一轮任务。

目前读取公开的 HTML、纯文本和 Markdown 页面，不执行网页脚本，也不读取登录后的内容。扫描版 PDF、视频和主要依靠 JavaScript 加载正文的网站不在本次支持范围内。`curl` 可以请求已知 URL，但没有搜索索引，不能代替搜索服务或解决验证码；通过 Shell 使用它仍需遵守命令权限。

## 从手机连接主机

手机端需要先有一个指向本机服务、证书被手机信任的 HTTPS 网关。普通的 `http://127.0.0.1:4317` 仅代表当前设备自身，不能作为另一台手机的服务地址。

主机启动前配置下面的环境变量：

| 变量 | 含义 |
| --- | --- |
| `OPENASTER_GATEWAY_ORIGIN` | 完整 HTTPS 来源，如 `https://agent.example.com`，不带路径 |
| `OPENASTER_GATEWAY_TOKEN` | 至少 32 字符的独立随机访问令牌，不是模型 API Key |
| `OPENASTER_ALLOWED_ORIGINS` | 允许的手机界面来源；Android 为 `https://localhost`，iOS 为 `capacitor://localhost`，多项用逗号分隔 |

例如，在 PowerShell 中设好实际网关域名后生成一个本次启动使用的令牌：

```powershell
$env:OPENASTER_GATEWAY_ORIGIN = 'https://agent.example.com'
$env:OPENASTER_GATEWAY_TOKEN = node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
$env:OPENASTER_ALLOWED_ORIGINS = 'https://localhost,capacitor://localhost'
pnpm start
```

把示例域名换成自己控制的域名。HTTPS 反向代理需要将该来源转发到本机 `127.0.0.1:4317`，保留公开 Host，并支持 SSE 持续连接；服务本身仍在回环地址监听。域名、证书和反向代理需由部署者准备，上述变量不会自动申请证书。

在手机的网关设置中填写这个 HTTPS 地址和独立访问令牌。令牌只在自己控制的设备间传递，不写进仓库或截图。没有可信 HTTPS 环境时，可以先使用本地网页版和桌面版。

## 遇到问题

- **端口已占用**：按 README 修改 `PORT`，或关闭此前启动的 OpenAster 服务。
- **服务商拒绝请求**：核对协议、地址、模型权限与额度，保留错误码即可，无需公开完整连接信息。
- **输出中断**：已经收到的片段会保留，未完成状态不会当作最终答案；检查执行记录再决定是否重试。
- **目录无法打开**：确认目录位于允许的范围，没有经过链接或跳转到受保护位置。
