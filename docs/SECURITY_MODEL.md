# 安全模型

OpenAster 把模型建议与本机执行分开。模型可以提出调用工具；是否执行，由服务端校验参数、路径和当前授权后决定。

## 数据流向

任务记录保存在当前项目的数据目录。使用外部模型时，参与请求的消息、图片、技能内容和文件片段会发送给该服务。设置本地工作区不会让云端推理变成本地推理。

网页模式的模型密钥保存在服务进程内存中；桌面模式通过平台的凭据保护能力保存。备份不包含凭据库，但会包含会话和允许备份的文件，因此备份仍可能是敏感数据。

## 文件边界

文件工具默认以当前工作区为根，校验相对路径、链接和文件类型。修改前展示目标与差异，并在写入时复核原内容，减少审批后文件变化造成的误覆盖。

用户在本机界面明确授予“电脑文件访问”后，工具也可读取获准的绝对路径；敏感目录检查仍然生效。该授权在服务重启后失效，读取后参与任务的内容可能发送给当前模型。远程网关不能自行打开这个本机授权。

这些限制约束文件工具。Shell 是另一条执行路径，不能把文件工具的工作区限制理解为所有子进程的操作系统隔离。

## Shell 授权

默认策略只自动放行少量固定的只读命令，其余命令询问用户。用户也可选择每次询问，或明确授权本次运行使用符合规则的开发命令。复杂表达式、权限提升、发布等操作不会因普通任务授权而直接获得许可。

任务授权绑定当前会话与运行，不随备份恢复，不跨项目，任务结束即失效。撤销后，尚未启动的命令会重新检查权限；已经启动的进程不能靠撤销授权恢复原状。

获准的脚本仍可能读写主机文件或访问网络。它以启动 OpenAster 的操作系统账号运行，因此只应在自己愿意授予相应权限的项目中启用。当前实现没有宣称提供操作系统级沙箱。

## 网页访问

搜索和网页阅读有独立开关，默认关闭，服务重启或项目切换后不保留授权。模型不能开启这个开关；关闭时会取消正在进行的网页请求。授权 Shell 后，命令自身仍可能联网，这个开关不代替系统网络隔离。

搜索默认调用 [Parallel 官方 MCP](https://docs.parallel.ai/integrations/mcp/quickstart) 的免密钥入口，不传入模型密钥；免密钥不代表服务商无法看到请求的网络地址。Parallel 会收到搜索词，也可能返回用于后续检索的关联标识。该入口有限流，第三方可用性不由本项目保证。

用户也可明确选择百炼原生搜索或实验性 DuckDuckGo 网页入口。百炼只使用当前 Qwen 连接的既有地址和密钥请求 Responses 搜索，不改域名、不跟随跳转，会额外产生模型与搜索费用；自定义兼容地址的支持情况尚未实测。DuckDuckGo 接收搜索词，可能返回验证码。三个服务之间不会自动回退或切换。

搜索服务选择只存在于当前后端进程，重启恢复 Parallel；保存选择不会开启联网或立即请求服务。运行中、等待审批或任务正在切换时不能更改。验证码、限流、鉴权失败或服务不可用等错误会关闭本轮后续搜索，避免换词重复请求；新一轮任务可再次尝试。已经提交的百炼请求可能仍会计费，取消或超时不等于费用撤销。

`read_webpage` 和实验性 DuckDuckGo 页面抓取只请求公开的 HTTPS 页面，不携带浏览器 Cookie 或模型密钥。请求前检查域名解析结果，拒绝内网、回环、链路本地等地址；连接固定到已检查的地址，每次允许的重定向重新检查。响应大小、跳转次数和请求时长均有限制。搜索失败后，已知公开链接仍可由 `read_webpage` 按这些规则读取。

页面先转换为有长度上限的文字，再作为不可信工具结果交给模型；不执行脚本、不加载页面中的图片，也不让页面内容决定工具权限。搜索返回的摘录、来源和参与任务的网页文本会发送给所选模型；百炼生成的归纳单独标明，不冒充网页原文。用户仍需避免把敏感内容放进搜索词或网址。

`curl` 只能请求已知 URL，没有搜索索引，也不能解决验证码。通过已授权 Shell 发起的网络请求不受上述网页工具的地址检查约束，不能把两者视为同一条安全边界。

## 执行中修改要求

补充消息先保存到独立队列，避免正在运行的会话快照覆盖它。消费消息与保存新一轮任务一起提交；重复请求不会产生两次模型调用。

“打断并发送”请求取消当前模型传输或工具，再串行处理新输入。等待审批时收到新要求会撤销旧审批。进程异常退出后，尚未处理的输入保留并标明状态，不在启动时自动调用付费模型。

## 界面与远程访问

模型文本按不可信内容渲染。Markdown 和代码高亮使用受控 DOM，不把模型输出当作 HTML 或脚本执行。

本地服务校验来源与写请求的 CSRF 标记。移动端通过经过配置的网关连接主机，需要可信 HTTPS 和访问凭据；不要通过关闭证书验证解决连接问题。手机上的项目入口只操作服务主机允许的目录。

模型回复、文件、网页和技能文本都不能自行扩大授权。发现实现不符合这些边界时，按 [SECURITY.md](../SECURITY.md) 报告。
