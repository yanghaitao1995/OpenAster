# 平台现状

项目面向多平台探索，但实现了入口、生成了构建文件和完成实机验收是不同阶段。当前没有经完整平台验收的商业稳定发行版。

| 平台 | 当前范围 | 需要注意 |
| --- | --- | --- |
| 本机浏览器 | 本地服务与任务工作台 | 适合先从源码体验；需要项目指定的 Node.js 环境 |
| Windows | Electron 桌面封装和构建配置 | 原生运行与安装仍需按当前版本和机器验证，不能仅凭包已生成判定通过 |
| macOS | Electron 构建配置 | 尚未完成完整 Mac 实机验收；签名、公证与发布另需环境和身份配置 |
| Linux | Electron 构建配置 | 尚未完成完整 Linux 实机验收；发行版和桌面环境可能影响运行 |
| Android | Capacitor 移动伴侣与原生模板 | 完整功能依赖已授权网关，设备、证书及网络条件需单独验证 |
| iOS | Capacitor 原生准备入口 | 需要 Mac、Xcode 和相应签名环境，尚未完成完整实机验收 |

移动端以连接任务服务的伴侣体验为目标，不应推断为在手机上完整运行桌面工具进程。

## 本地构建

桌面命令见[开发指南](DEVELOPMENT.md)。Electron、Android SDK、JDK、Xcode 等工具链有各自的安装条件和许可；安装与使用应按官方要求进行。

Android/iOS 原生工程由仓库中的配置与模板生成，生成目录不作为公开源码输入。原生准备脚本完成并不等于签名安装包或商店上架已经完成。

## 验证范围

没有适用环境时，应明确记录未验证项。不要为通过验证而禁用证书检查、放宽网关认证、关闭系统防护或绕过组织加密策略。平台限制不应被文档描述成已经完成的支持承诺。
