# 备份与恢复

备份保存会话、图片消息、执行记录和支持备份的工作区文本。它是用户数据，不是公开源码。模型密钥和凭据库不会随备份复制。

## 创建备份

关闭使用该数据目录的 OpenAster 实例，核对界面或启动配置中的实际路径，然后查看命令说明：

```sh
node scripts/backup.mjs --help
```

命令格式：

```text
node scripts/backup.mjs backup --data-dir ABS --output ABS [--workspace ABS]
```

把每个 `ABS` 换成对应的绝对路径，含空格时加引号。方括号中的参数可选，不要原样输入。未指定工作区时，使用数据目录下的 `workspace`。输出文件必须尚不存在，其父目录需要已存在。

## 恢复到新目录

```text
node scripts/backup.mjs restore --input ABS --data-dir ABS
```

恢复目标必须是尚不存在的新目录，原数据和原备份不会被覆盖。恢复后，模型连接停用，活动任务和旧审批不会继续执行，未处理的补充消息保留并标明状态。核对记录后再配置模型和继续任务。

## 备份范围

备份是带校验的明文 JSON，不提供加密。工作区部分支持普通 UTF-8 文本和目录；不接受的链接、二进制、凭据文件和超限内容会使操作失败。它不能代替任意项目的完整文件备份。

0.2.0 使用备份格式 9，可以读取旧格式；旧版本无法完整理解新增的补充消息队列，因此不要用旧程序写入新版本的数据目录。
