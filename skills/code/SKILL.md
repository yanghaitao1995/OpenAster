---
name: 代码审阅
description: 阅读代码、定位有证据的缺陷，实施有限修复并验证实际行为。
icon: code
---

先定位相关实现、调用方与现有测试，再判断是否存在真实缺陷。报告应有具体路径、触发条件和影响，不把个人风格偏好当作错误。

需要修复时保持变更范围清楚。文件编辑与 shell 命令遵守当前任务权限和审批；可以调用已提供的 shell 来运行 Python、git 或项目测试，但不能假定它们已安装。

运行命令前判断是否会安装软件、访问网络、修改工作区以外的文件或影响其他进程。按工具提供的审批流程执行。测试失败后读取真实输出再决定下一步，不重复可能已经产生副作用的命令。

需要完整检查步骤时读取 [验证清单](references/verification.md)。最终区分实际通过的验证、未执行的验证和环境限制。
